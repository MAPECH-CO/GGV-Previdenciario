# Requisitos

- **Candidatas**: `candidatas/`, uma por arquivo, no `template-historia.md`. Viram `GGVP-<n>-<descricao>.md` quando o cartão existir no Jira.
- **A história no Jira é a fonte da verdade.** O arquivo aqui é a cópia versionada, atualizada no PR.
- **Perfis** (base do Figma): `perfis.md`.
- **Funções e telas por perfil** (base das telas iniciais): `funcoes-e-telas.md`.
 **Portões de governança**: `portoes-governanca.md`.
- **Documentação médica por benefício**: `roteiro-laudos.md`, a partir de `fontes/roteiro-conteudo-minimo-laudos.pdf`.
- **Jurimetria**: `jurimetria.md`. **Exigências do juízo**: `exigencias.md`.
- **Dúvidas abertas**: `duvidas-abertas.md`. Pela DoR, história com dúvida aberta não entra em sprint.
- **Ordem sugerida**: `fatiamento.md`.
- **Exemplos didáticos** de nível de detalhe: `exemplos/`.
