# Exemplos de história preenchida

**Estes arquivos são exemplos didáticos.** Foram escritos no repositório do Trabalhista como exemplos didáticos a partir do Prev antigo. Aqui servem de referência de nível de detalhe; as histórias reais do Prev estão em `../candidatas/`.

O EXEMPLO-02 também existe como cartão no Jira do Trabalhista, **GGVT-93**, com o título marcado como template, os rótulos `template`, `exemplo` e `nao-construir`, e fora de qualquer sprint. Serve para consultar o formato direto no Jira, sem abrir o repositório.

Foram escritos a partir do portal da GGV Previdenciário, o primeiro produto da MAPECH, e das lacunas que a auditoria de uso de 11/09/2026 encontrou nele. Mostram o nível de detalhe esperado quando uma história fica Pronta.

| Exemplo | O que ele ensina |
|---|---|
| [EXEMPLO-01 · Acesso gov.br com segurança](EXEMPLO-01-acesso-govbr.md) | Dado sensível, permissões por perfil, agente de IA sem acesso, histórico de quem fez o quê |
| [EXEMPLO-02 · Publicação vira prazo](EXEMPLO-02-publicacao-vincular-prazo.md) | O que o portal calcula e a pessoa confirma, concorrência, supervisão, quando quebrar uma história |

Para escrever uma história real: copiar `../template-historia.md`, trocar `GGVP-___` pela chave do Jira e usar o código do passo do BPMN em `docs/bpmn/`.
